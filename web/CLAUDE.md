# web — Siteline web app (owner: Gaurav)

React + Vite + TypeScript (strict) on :5173. Judges see everything through this screen: the agent's thinking, the
map and the results. It must look clean from two meters away and never show a number without a source link.

## Stack
- Vite `react-ts` template; TypeScript strict.
- Map: `maplibre-gl` basemap (free style without an API key, e.g. OpenFreeMap or Carto) + deck.gl
  (`@deck.gl/core`, `@deck.gl/layers`, `@deck.gl/geo-layers` for `H3HexagonLayer`, `@deck.gl/mapbox` for
  `MapboxOverlay` on top of MapLibre).
- State: `useReducer` over the RunEvent stream. No global state library needed.
- Styling: plain CSS modules or Tailwind — your choice; keep it simple and consistent.
- Tests: vitest for the reducer and the replay player.

## Layout
```
web/
  src/types/contracts.ts     GENERATED by `make types` — never edit by hand
  src/api/client.ts          POST /runs, /approve, /rescore, GET artifacts (base URL from VITE_AGENT_URL)
  src/api/sse.ts             EventSource on GET /runs/{id}/events
  src/api/replay.ts          plays fixtures/events.jsonl through the same reducer (fixture mode)
  src/state/runReducer.ts    RunEvent -> UI state
  src/presets/               4 practice presets (orthopedic group, pediatric dentist, dialysis clinic, physical therapy)
  src/components/            IntakeForm, Trace, ScoutsPanel, FactorList, MapView, ApprovalModal,
                             SiteCards, WeightSliders, DemoControls, SourceLink
  src/App.tsx
  scripts/copy-fixtures.mjs  copies ../fixtures/*.json(l) to public/fixtures/ (gitignored) for fixture mode
```
Commands: `npm run dev`, `npm run typecheck` (`tsc --noEmit`), `npm run build`, `npm test`.
If `make types` fails on your machine, fix the json2ts invocation together with Archit (he owns the Makefile).

## Data flow
1. Intake → `POST /runs` with `RunCreate {profile, region_id: "hou", mode}` → `{run_id}`.
2. `EventSource(/runs/{run_id}/events)`; each message is one RunEvent (JSON).
3. Reducer (payload conventions are in services/agent/CLAUDE.md):
   - `todo` → replace the todo list
   - `factor` → upsert by `id` (status chips: covered, searching, found, proxy, dropped)
   - `tool_call` / `tool_result` → trace lines; those with `factor_id` also update that scout's row
   - `file` → fetch `GET /runs/{id}/artifacts/{name}`: `zones.json` (ScoreResponse) → map,
     `ranked.json` / `report.json` (Report) → cards
   - `approval` → open ApprovalModal with the ApprovalRequest
   - `done` → fetch report.json if not loaded; `error` → banner
4. Approval → `POST /runs/{id}/approve` (ApproveRequest). Weight sliders → `POST /runs/{id}/rescore`
   (RescoreRequest) → RescoreResponse updates map and cards.
Fixture mode (`VITE_FIXTURE_MODE=1`): the replay player feeds `public/fixtures/events.jsonl` to the same reducer
with ~400 ms between events, and artifacts load from `public/fixtures/`. Everything must work with no backend.

## Screens
- **Intake:** specialty, services, payers (checkboxes), languages, existing office addresses, space needs (sq ft
  range, max rent, parking ratio, ground floor, special rooms), free text. Preset buttons fill the form.
- **Run view:** left = agent trace (todo list ticking; scouts running in parallel with retry counts);
  center = H3 map colored by score (sequential scale), top zones outlined, site pins, tooltip with the top
  contributions; right = factor list with status chips and a source link per factor.
- **Approval modal:** data plan (factor → dataset title, publisher, coverage %, link, ok/not ok) or weights
  (sliders per feature, sum shown, normalized on submit); Approve / Edit / Reject.
- **Results:** top 10 cards — rank, address, sq ft, rent, **net-new patients** (large), "why here" claims each
  with a SourceLink, Vexcel image if present, stability badge ("top 10 in 92% of weightings"), caveats.
  If `available` is null show "candidate building" instead of "for lease".
- **Demo controls:** replay a golden run, auto-approve after 3 s toggle, Houston / Jacksonville switch.
